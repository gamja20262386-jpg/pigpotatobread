# 추천 에이전트 설계

## 입력
사용자가 입력한 문장(예: '1만원 이하 간식 추천해줘', '5천원 이하 기념품').

## 처리 단계
1. '1만원', '1만 5천원', '5천원', '15000원' 등 금액 표현을 원 단위 예산으로 변환한다.
2. 간식·분식·디저트·꼬치·기념품·음료 키워드와 상품명 일치를 확인한다.
3. 품절 상품과 예산 초과 상품을 제외한다.
4. 해당 카테고리/상품 조건으로 후보를 필터링하고 가격순으로 최대 3개를 선정한다.
5. 상품명·가격·상점명을 반환한다.
6. 관련 상품을 찾지 못하면 조건 변경을 안내한다.

## 한계
JavaScript 규칙 기반 추천 프로토타입으로, 생성형 AI API와 연결되어 있지 않다.
문맥 이해나 유사어 처리에는 한계가 있으며, 실제 상품·재고 데이터와도 연결되지 않았다.

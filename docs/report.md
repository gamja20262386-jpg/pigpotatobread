# 제주마켓 AI 프로젝트 보고서

## 1. 주제 및 목적
제주 동문시장을 주제로 사용자가 취향과 예산에 맞는 상품을 탐색하도록 돕는 웹 서비스를 기획했다.

## 2. 데이터 구성
시연용 가상 상점 6곳(제주한입, 돌하르방분식, 귤빛디저트, 바당꼬치, 제주선물상점, 오름음료)과 가상 상품 12개를 구성했다. 실제 입점 업체로 오인하지 않도록 가상 데이터임을 표시했다.

## 3. 주요 기능
상점 선택 및 상점별 상품 필터링, 카테고리 탐색, 빈 카테고리 안내, 품절 상품 담기 비활성화, 장바구니 합계, 키워드와 예산 기반 추천 기능을 구현했다.

## 4. 에이전트 동작
입력에서 예산과 상품 키워드를 추출하고 품절 여부와 가격을 확인한 뒤 조건에 맞는 상품을 최대 3개 반환한다.

## 5. 기대 효과
시장 방문 전 상품을 간편하게 탐색하고 예산에 맞는 후보를 비교할 수 있다.

## 6. 한계 및 개선
현재 추천은 키워드·예산 규칙 기반 프로토타입이며 실제 생성형 AI API와 연결되지 않았다. 실제 서비스로 발전시키려면 검증된 상점 데이터, 실시간 재고·가격, AI API, 사용자 평가, 개인정보 보호 설계가 필요하다.

# 기능 테스트 시나리오

| 번호 | 테스트 | 기대 결과 |
|---|---|---|
| 1 | 최초 실행 | 가상 상점 6곳과 상품 12개 표시 |
| 2 | 특정 상점 클릭 | 해당 상점 상품만 표시 |
| 3 | '전통주' 카테고리 클릭 | '준비 중인 카테고리입니다.' 표시 |
| 4 | 품절 상품 확인 | 담기 버튼 비활성화 |
| 5 | 판매 상품 담기 | 장바구니 수량·합계 갱신 |
| 6 | 장바구니 + / − / 삭제 | 수량·합계 즉시 반영, 0개가 되면 삭제 |
| 7 | '1만원 이하 간식 추천해줘' | 품절 제외, 10,000원 이하 간식 추천 |
| 8 | '5천원 이하 기념품' | 5,000원 이하 기념품만 추천 |
| 9 | '1만 5천원 이하 분식' | 15,000원 이하 분식만 추천 |
| 10 | '15000원 이하 음료' | 15,000원 이하 음료만 추천 |
| 11 | '노트북 추천해줘' | 관련 상품이 없다는 안내 |
| 12 | 추천 결과 | 최대 3개, 상품명·가격·상점명 표시 |

※ 이 표는 수동 검증용 시나리오이며, 자동화 테스트 통과를 의미하지 않습니다.

# 제주잇 화면 기준 (v0.1)

기준 화면: **iPhone 14 Pro 393×852 pt**. 웹에서는 창이 500px보다 넓으면 393×852 폰 프레임 안에 앱을 띄우고, 좁으면 전체 화면으로 띄운다.
참고: 현재 제주잇 주황(#FF6B00) 유지 · JARI(현대차 앱)의 에이전트 카드·먼저 챙기기·NavPill · 대승보의 근거 칩·작업 타임라인·승인 · 레퍼런스(Cosmos·Awwwards·It's Nice That·The Dieline)의 사진 중심 균일 카드, 문장형 제목, 최소 장식.

## 1. 토큰 (`app/src/theme.ts` 한 곳)
| 이름 | 값 | 쓰임 |
|---|---|---|
| brand | #FF6B00 | 화면당 주요 버튼 1개, 가격, 에이전트 활성 |
| brandDark | #E05D00 | 눌림 |
| brandSoft | #FFF1E6 | 주황 틴트 타일·말풍선 |
| bg | #FAF7F2 | 바탕(따뜻한 미색) |
| card | #FFFFFF | 카드 |
| ink | #1B1A17 | 본문 |
| sub | #6E6A63 | 보조 글자(최소 13) |
| line | #E7E1D7 | 1px 테두리·구분선 |
| basalt | #23211E | 어두운 면: NavPill, 자동화 카드, 영수증 머리 (제주 현무암) |
| sea / seaSoft | #1E6F6B / #E6F1F0 | 배송·경로·냉장 |
| leaf / leafSoft | #4F7A3A / #EDF3E8 | 신선·상온·완료 |
| warn / warnSoft | #B45309 / #FEF3C7 | 경고(신선 경고, 마감 임박) |
| danger | #D93025 | 품절·오류 |

온도 배지: 냉장 = sea, 따뜻 = brand, 상온 = leaf.
반경: 칩 8, 카드 16, 시트·에이전트 카드 24, 알약 999. (한 화면에 반경 두 가지 이상 겹쳐 쓰지 않기)
간격: 4/8/12/16/20/24/32, 화면 좌우 20. 터치 최소 44×44, 주요 버튼 높이 52.
그림자: 거의 없음. 카드 = 흰 바탕 + 1px line. 떠 있는 것(NavPill, 시트, 에이전트 카드)만 부드러운 그림자.

## 2. 글꼴
- 제목·가게 이름: **Noto Serif KR** SemiBold (`@expo-google-fonts/noto-serif-kr`) — 시장 가게를 잡지처럼.
- UI·본문: **Noto Sans KR** Regular/Medium/Bold (`@expo-google-fonts/noto-sans-kr`).
- 크기: 디스플레이 28/34(serif) · 제목 20/26 · 본문 16/24 · 캡션 13/18 · 작은 영문 라벨 11, 대문자, 자간 1.2 (예: `JEJU · DONGMUN MARKET`).
- 제목은 문장형(마침표 없음). 숫자는 `toLocaleString('ko-KR')` + "원".

```
app/app/(tabs)/index.tsx     홈
app/app/(tabs)/market.tsx    동문시장

app/src/api.ts  theme.ts  store/(cart, session, agent)  components/
```

## 4. 화면
**홈** — 머리: `제주잇` 워드마크(serif, brand) + 배송지 칩(누르면 배송지 시트) + 장바구니 아이콘(개수 배지).
→ **에이전트 카드**(JARI): 하르방 오브(주황 그라데이션, 실행 중 맥동 1→1.12, 650ms), 들은 말(회색 따옴표 한 줄), 하르방 답(19 SemiBold), 입력창 "한 문장으로 말해 보세요", 제안 칩 가로 스크롤("4명 저녁 회랑 흑돼지 5만원", "함덕 숙소로 오메기떡", "아이 간식 1만원 이하", "막걸리랑 안주"). 보내면 하르방 탭으로 이동해 결과를 보여 준다.
→ **하르방이 먼저 챙겼어요**(nudges, 닫기 ✕ / 맡기기 버튼). → 카테고리 11칸(4열). → **오늘의 동문시장** 가게 가로 카드(아이콘 타일 4:5 + serif 이름 + 한 줄 이야기 + 영업 칩). → 맛집 목록.

**동문시장** — 편집형 머리: 작은 라벨 `JEJU · DONGMUN MARKET`, serif 28 "시장 가게를 한 번에 묶어 보내요", 영업시간·야시장 칩. → basalt 자동화 카드 "장 보는 동안, 하르방이 맡을게요"(여러 가게 → 공동 집하장 → 한 번에 배달, 묶음 배송비 규칙 표시). → 라벨 필터 칩 → 가게 카드 목록(2열 그리드, 마감 1시간 안이면 warn 칩 "40분 뒤 마감", 닫혔으면 흐리게).

**가게** — 큰 틴트 타일(아이콘) + serif 이름 + 이야기 + 영업·준비 시간. 상품 행: 이모지 타일 64, 이름, 설명, 온도 배지, 재고 5개 이하 "3개 남음", 품절은 흐리게 + "품절" 배지, 가격(brand), 담기/수량 스테퍼.

**하르방(에이전트)** — 위: 오브 + "하르방" + LLM 상태 칩(`로컬 AI · ax4-light` 초록 / `규칙 모드` 회색). 대화 목록: 내 말(오른쪽 brandSoft), 하르방 턴 = 
1) 요약 문장(큰 글자), 
2) **작업 과정** 접이식 "하르방 팀이 5단계로 확인했어요": 단계마다 에이전트 번호·이름·✓/!·주장 수·LLM 사용 시 `AI` 태그. 실행 중에는 단계가 순서대로 켜지는 애니메이션(120ms 간격). 
3) **근거**: 주장 목록, 주장마다 근거 칩(데이터/계산/가정/입력/AI 추출 — 색 구분), 기본 3개 + "근거 N개 더 보기". "단, …" 대체 주장은 warnSoft 띠로 강조. 
4) **장바구니 제안 카드**(plan_order): 가게별 묶음, 봉투(냉장 보냉팩/따뜻한 보온백/상온 봉투), 배달비 내역, 도착 예상, 경고 → 버튼 `이대로 담기`(brand) / `고쳐서 담기`(외곽선). 자동 주문 없음 문구: "담기 전에는 아무것도 주문되지 않아요". 
아래: 제안 칩 + 입력창(키보드 위 고정).

**장바구니** — 배송지 선택, 가게별 묶음(시장 가게는 "공동 집하" 표시), 수량 스테퍼, **하르방 점검 카드**(cart_check: 봉투, 배달비 = 시장 묶음 + 맛집, 도착 예상, 경고), 하단 고정 `52px 주문하기 · 금액`. 비로그인이면 시연 로그인 시트.

**주문 추적** — 5단계 스테퍼(맛집만이면 4단계), 간단 경로 카드(집하장 → 배송지 직선, sea 색 점선), basalt 영수증 머리 + 금액 행(상품/시장 묶음 배송비/맛집 배달비/합계), `다음 단계(시연)` 외곽선 버튼.

**마이** — 시연 로그인(고객/상인 버튼), 프로필, 좋아하는 것 칩(개인화 likes), 기본 배송지, **에이전트 팀 보기**, **상인 모드**(상인일 때), LLM 상태, 시연 시각(예: 18:30 → X-Demo-Time).

**에이전트 팀** — /harness 팀별 묶음, 에이전트 카드(번호 원, 이름, LLM 사용 여부, 카드 본문 "역할" 첫 문단, 펼치면 전체).

**상인 모드** — 내 가게 머리, **말로 고치기** 카드(입력 예: "고등어회 3개 더 들어왔어, 2만 6천원으로", 결과 이전→이후 표, `반영하기`), 상품 목록(재고 ± 스테퍼, 가격 입력, 품절 토글 = 재고 0), 들어온 주문(내 가게 줄만).

## 5. 컴포넌트
NavPill(basalt, 활성 탭만 글자, 가운데 오브 버튼 떠 있음) · AgentCard · AgentOrb · RunTimeline · ClaimList/EvidenceChip · ProposalCard · QuoteCard · NudgeCard · StoreCard · ProductRow · Stepper · TempBadge · Chip · Sheet(아래에서 올라오는 시트) · PhoneFrame(web).

## 6. 말투
하르방은 존댓말, 짧게, "~했어요/~할게요". 버튼은 동사형 2~4자(담기, 반영하기, 맡기기). 단정 표현 금지(policies/forbidden-phrases.json).

# v0.2 개편 (2026-11-13) — 배민형 탐색 + 하르방 유지

사용자 피드백: ① 하단 탭이 탭마다 움직임 ② 카테고리를 누르면 배민처럼 따로 목록 화면 ③ 세부 페이지 추가 ④ 마이·시장 화면 정리.
레퍼런스 조사(배민·쿠팡이츠·요기요, 출처는 이 절 끝) 결과를 반영한다. **v0.1과 다르면 이 절이 우선.**

## A. 하단 탭 (버그 수정)
- 원인: 활성 탭만 글자가 붙어 폭이 48→82px로 바뀌고 나머지 아이콘이 최대 34px 밀림.
- 고침: **화면 폭 전체를 쓰는 흰 탭 바, 5칸 같은 폭(flex:1), 아이콘 + 글자 항상 표시**(홈·시장·하르방·주문내역·마이). 활성은 brand 색만 바뀌고 크기·위치는 그대로. 가운데 하르방 오브만 위로 떠 있음. 위 1px line, 안전 영역 패딩.
- 검증: 4개 탭에서 각 탭 버튼의 x 좌표가 같아야 함(Playwright로 측정).

## B. 홈 (배민형)
1. 머리: 왼쪽 위 **배송지**(누르면 배송지 시트) · 오른쪽 장바구니 아이콘.
2. **검색창**(맨 위 고정 느낌, 누르면 `/search`). 자리표시: "메뉴·가게를 찾아보세요".
3. **서비스 탭**: `음식배달 · 동문시장 장보기 · 포장` (세그먼트, 마지막 선택 저장). 음식배달=맛집 중심, 장보기=시장 중심, 포장=포장 가능 가게.
4. **카테고리 그리드**: 5열 × 2줄, 둥근 사각 아이콘 타일 + 라벨. 누르면 `/category/[id]` (동문시장은 `/market`).
5. **하르방 카드(축소형)**: 오브 + 한 줄 안내 + 입력 + 제안 칩 1줄. (에이전트가 이 앱의 핵심이므로 홈 위쪽 유지)
6. 하르방이 먼저 챙겼어요(nudges) → "지금 빠른 배달"(정렬 fast 가로 카드) → "동문시장 오늘의 가게" → "별점 높은 맛집".

## C. 카테고리 목록 `/category/[id]` (신규)
- 위: 뒤로가기 + 제목, **가로 스크롤 카테고리 탭**(활성 밑줄 brand 2px, 누르면 같은 화면에서 전환, 활성 탭이 보이게 자동 스크롤).
- **정렬 칩**: 배달 빠른 순 · 배달팁 낮은 순 · 기본순 · 별점 높은 순 (API `sort=fast|fee|default|rating`, 선택은 세션 동안 유지). **필터 칩**: 영업 중(`open_only`) · 포장 가능.
- **가게 카드**(목록형): 왼쪽 썸네일 88×88(사진, 없으면 틴트 아이콘 타일), 오른쪽: 가게명(Bold 16) · ★4.8 · `배달 27~37분 · 배달팁 2,000원 · 최소주문 12,000원` · 대표 메뉴 이름 2개 · 배지(시장 묶음 / 포장 가능 / 40분 뒤 마감 / 준비 중). 닫힌 가게는 흐리게 + "준비 중".
- 빈 상태: "이 카테고리에 문 연 가게가 없어요" + 필터 해제 버튼.

## D. 가게 상세 `/store/[id]` (개편)
- 위: 사진(없으면 큰 틴트 타일) 16:9, 뒤로·찜(하트, 로컬 저장).
- 정보 블록: 가게명(serif 24) · ★ · 이야기 한 줄 / 표: 최소주문 · 배달시간 · 배달팁(시장 가게는 "동문시장 묶음 배송 3,000원부터, 가게 1곳 늘 때 +500원, 최대 5,000원") · 영업시간.
- **배달 / 포장** 세그먼트(포장 선택 시 배달팁 0원 표시만, 주문은 v0.2 범위 밖이면 안내).
- **메뉴 검색**(가게 안) + **그룹 바로가기 칩**(대표 메뉴 · 메뉴 · 사이드·음료) → 누르면 그 구역으로 스크롤.
- 메뉴 행: 왼쪽 글(이름 Bold · 설명 2줄 · 가격 brand · 대표/품절/재고 3개 남음 배지 · 온도 배지), 오른쪽 사진/아이콘 타일 88. 품절은 흐리게. 누르면 `/product/[id]`.
- **하단 고정 바**: 장바구니에 담긴 게 있으면 "N개 · 장바구니 보기 · 합계원".

## E. 메뉴 상세 `/product/[id]` (신규, 모달 스택)
- 큰 사진/타일, 이름(serif), 설명, 가격, 온도 배지(냉장이면 "보냉 포장"), 재고, 가게 이름 링크.
- 수량 스테퍼, 하단 고정 **"N원 담기"**. 품절이면 버튼 비활성 + "하르방에게 대체 메뉴 물어보기"(하르방 탭에 "X 대신 비슷한 거" 보내기).

## F. 동문시장 `/market` (개편)
- 편집형 머리 유지(작은 라벨 + serif 제목) + 상태 칩(영업·야시장·문 연 가게 수).
- 자동화 카드는 **접힌 띠**로 축소: "여러 가게를 한 장바구니로 · 집하장에서 한 번에 · 배달팁 최대 5,000원" + 펼치기.
- 라벨 필터 칩 → 가게 카드는 **C와 같은 목록형 카드** 재사용(시장 배지).
- **시장 인기 메뉴** 가로 레일(대표 메뉴 popular, 담기 버튼).

## G. 검색 `/search` (신규)
- 입력 자동 포커스, 최근 검색어(로컬, 지우기), **인기 검색어 칩**(음식 이름: 회, 흑돼지, 고기국수, 오메기떡, 갈치, 감귤, 치킨, 막걸리).
- 결과: `가게 | 메뉴` 탭. 가게 = C 카드, 메뉴 = 메뉴 행(D). 결과 아래 "하르방에게 '{검색어}'로 장바구니 짜 달라고 하기" 버튼.

## H. 마이 (배민 마이 구조로 개편)
- 머리 카드: 로그인 전 = "시연 계정으로 둘러보세요" + 고객/상인 버튼 / 로그인 후 = 이름 · 역할 배지(고객·상인) · 로그아웃.
- **빠른 메뉴 3칸**: 주문내역 · 찜한 가게 · 배송지.
- **목록 행**(왼쪽 아이콘, 오른쪽 ›, 최소 높이 52): 내 취향(좋아하는 것) → `/my/likes` · 배송지 관리 → `/my/address` · 찜한 가게 → `/my/favorites` · 에이전트 팀 → `/team` · 상인 모드(상인만) → `/merchant` · 시연 설정 → `/my/demo`(시연 시각, AI 상태, API 주소).

### J. 글 줄이기 원칙 (모든 화면)
- 섹션은 **제목 한 줄**만. 제목 아래 설명 문장을 붙이지 않는다(꼭 필요하면 캡션 1줄, 20자 안팎).
- 3줄 넘는 설명은 접기(›)나 세부 화면·바텀시트로 보낸다. 카드 안 설명은 최대 2줄 말줄임.
- 칩을 15개 넘게 한 화면에 늘어놓지 않는다 → 목록 행 + 세부 화면(선택 화면에서만 칩).
- 숫자·상태는 문장 대신 **아이콘 + 값**(예: ⏱ 27분 · 🛵 2,000원).
### K. 에이전트 팀 `/team` 개편
- 머리: 오브 + "하르방 팀 9명" + 캡션 1줄. 검은 설명 박스 삭제 → 접히는 "어떻게 일하나요 ›" 한 줄.
- **팀 지도**: 지휘(오브) 아래로 4팀이 연결된 노드 그림(react-native-svg 선). 팀 노드를 누르면 그 팀 에이전트로 스크롤.
- 에이전트 카드: 번호 원 + 이름 + **역할 한 줄(카드 '역할' 첫 문장, 30자 넘으면 말줄임)** + AI/규칙 배지. 누르면 바텀시트로 카드 전체(역할·입력·출력·하지 않는 일).
- **흐름**: 흐름 고르기 세그먼트(한 문장 주문·장바구니 점검·대화·먼저 챙기기·상인 입력) → 고른 흐름을 **가로 스텝퍼**(번호 노드 + 연결선 + 이름 한 줄)로. 흐름마다 카드 5개를 세로로 쌓지 않는다.

### P. 하르방 답변·팀·먼저 챙기기 (AI 에이전트 UX 조사 반영)
출처: Perplexity 단계 표시(LangChain 사례, aiuxplayground 분석), ChatGPT "Thought for N seconds" 요약 헤더, DoorDash·Uber Eats·Instacart·Amazon Rufus AI 장바구니, NN/g 바텀시트·점진적 공개(2단계 이하), Google PAIR 설명 가이드, Microsoft HAX 가이드라인, OrchVis(멀티 에이전트 시각화 논문).
- **작업 중**: 한 줄 상태만 — 지금 일하는 에이전트의 일을 쉬운 말로("시장 가게 고르는 중…", "배달비 계산 중…"). 단계 목록을 펼쳐 보이지 않는다.
- **끝나면 접힌 한 줄**: "✓ 5단계 확인 · 8초 ›" (펼치면 단계 목록, 2단계 공개까지만). 단계 이름은 에이전트명 대신 한 일(예: "시장 2곳 묶음", "도착 72분 계산").
- **근거**: 주장마다 칩 1개 + "+N"(예: `데이터 +1`), 칩을 누르면 작은 시트로 근거 목록. 수준은 `확실`(fact) / `추정`(estimate·assumption) / `확인 필요`(question) 배지 3종만.
- **제안 카드 품목마다 이유 한 줄**(예: "회 · 4명 기준 1kg", "흑돼지 · 예산 맞춰 3개"). 버튼 [고쳐서 담기] [이대로 담기] 유지.
- **주문 확인 시트**(장바구니 → 주문하기): 합계·품목 수·도착 예상·배송지 + [주문하기] [닫기]. 되돌릴 수 없는 행동(주문)만 시트로 확인, 장바구니 담기는 바로.
- **팀 화면(K 보강)**: 맨 위는 목표 한 줄("한 문장 → 장바구니 → 사람이 승인"). 흐름 스텝퍼 끝에 **'사람 승인' 노드**를 따로 그린다. 4팀은 아이콘·색으로 구분하고 에이전트 9명 이름은 펼쳤을 때만.
- **먼저 챙겼어요 카드**: 제목 1줄 + 왜 떴는지 캡션("마감 40분 전", "담은 상품 품절") + [맡기기] [✕].

# 제주마켓 AI

제주 동문시장을 주제로 만든 전통시장 상점 추천 웹 프로젝트입니다. 매장과 상품은 과제 시연용 가상 데이터입니다.

## 주요 기능
- 가상 상점 6곳과 상품 12개 표시
- 상점 선택 시 해당 상점 상품만 표시
- 카테고리 필터, 품목이 없는 카테고리 안내
- 품절 상품 담기 비활성화 및 장바구니 합계
- 예산과 키워드 기반 추천 채팅

## 실행
Node.js 설치 후 `npm install`, `npm run dev`를 실행하세요. 또는 VS Code Live Server로 `index.html`을 실행할 수 있습니다.

## 추천 기능 안내
현재 추천은 키워드·예산 기반 **규칙 기반 프로토타입**이며 생성형 AI API와 연결되어 있지 않습니다.

## 폴더
- `index.html`: 화면
- `css/style.css`: 스타일
- `js/data.js`: 가상 매장·상품 데이터
- `js/recommendation.js`: 추천 로직
- `js/app.js`: 화면 동작
- `docs/`: 보고서·설계·테스트·시연 자료
- `tests/`: 추천 기능 테스트

공개 저장소에 API 키, 비밀번호, 개인정보를 올리지 마세요.

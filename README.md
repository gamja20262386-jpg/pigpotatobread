# 제주잇 — 하르방 에이전트 팀이 동문시장을 한 번에 묶어 배달해요

제주 전통시장(동문시장) 먹거리와 제주 맛집을 주문하는 **모바일 앱**입니다. 한 문장으로 말하면 앱 안의 AI 에이전트 팀 "하르방"이 여러 가게를 묶은 장바구니를 제안하고, 무엇을 왜 골랐는지 단계와 근거를 보여 줍니다. 담기·주문·재고 반영은 사람이 버튼을 눌러야 됩니다.

- 기준 화면: iPhone 14 Pro (393×852). 웹에서는 폰 프레임 안에 띄웁니다.
- 앱: Expo React Native (iOS·Android·웹) — `app/`
- 서버: FastAPI + 에이전트 하네스 — `backend/`, `harness/`
- AI: 로컬 Ollama(`ax4-light`), 꺼져 있거나 실패하면 규칙·템플릿으로 끝까지 동작

## 실행 (Linux·WSL)
```bash
bash deploy/run_local.sh          # API :8040 + 앱 웹 :8081
```
브라우저에서 http://localhost:8081 → **마이 → 시연 시각 18:30** (실제 밤 시각이면 시장 가게가 모두 닫혀 있어 제안이 비어요).
따로 실행·테스트는 [`backend/README.md`](backend/README.md), 앱은 `cd app && npx expo start --web` (`EXPO_PUBLIC_API_URL`로 API 주소 변경).

> 윈도우에서 직접 실행할 때는 `app/node_modules`, `backend/.venv`를 지우고 다시 설치하세요(WSL에서 만든 것은 리눅스용입니다).

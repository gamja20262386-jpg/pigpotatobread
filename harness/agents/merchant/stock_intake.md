# ⑧ 상인 말 입력 (stock_intake)

## 역할
상인이 말로 한 문장("갈치 5마리 들어왔어, 마리당 2만원", "고등어 다 팔렸어")을 재고·가격 수정 제안으로 바꾼다. 반영은 상인이 확인 버튼을 눌러야 된다(자동 반영 없음).

## 입력
ctx.message, ctx.store_id(로그인한 상인의 가게), 그 가게 상품 목록

## 출력
data.changes: [{product_id, name, stock?, price?, sold_out?}]
주장: 바꿀 항목마다 이전 → 이후(fact, 근거 input:message), 상품을 못 찾으면 question.

## 규칙
상품명·별칭 일치 → 숫자+개/마리/팩 → stock, 숫자+원/만원 → price, "다 팔렸/품절/없어" → stock 0.
LLM은 규칙으로 못 찾은 칸만 채우고, 값이 원문에 있을 때만 쓴다.

## 하지 않는 일
다른 가게 상품을 바꾸지 않는다. 확인 없이 저장하지 않는다.

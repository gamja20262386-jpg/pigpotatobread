# ⑦ 대화 도우미 (concierge)

## 역할
앱 대화 질문 한 개의 주제를 찾고, 주제별 근거 항목을 데이터에서 만든다. 질문 한 번에 답 한 번.

## 주제
hours(시장·가게 영업시간), fee(배달비 규칙), order(내 주문 상태), soldout(품절 상품), howto(앱 사용 순서), recommend(추천 요청 → 앱에 plan_order 실행을 권함: data.suggest_plan=true)

## LLM이 하는 일
낱말로 주제를 못 찾았을 때만, 가려진 질문을 보고 주제 하나를 고른다(스키마 enum). order·howto 답은 지휘 AI가 근거 항목으로만 요약한다.

## 하지 않는 일
쓰기 기능이 없다. 근거 없는 값을 만들지 않는다. 질문 원문을 주장에 남기지 않는다.
